msub 订阅合并工具（Windows 绿色版）
==========================================

【怎么用】
1. 把压缩包完整解压到任意文件夹（不要在压缩包里直接运行）。
2. 双击 msub.exe。第一次运行会让你设置「网页登录密码」
   （至少 8 位，输入时屏幕上不显示字符，这是正常的）。
3. 浏览器会自动打开管理页面，用刚设置的密码登录。
4. 在「添加节点」里粘贴其他 VPS 的订阅地址或节点链接，
   点「检查」，再点「生成合并链接」。
5. 在「订阅链接」页面复制地址，粘贴到电脑上的 v2rayN、Clash 等客户端里。

【一定要知道】
* 订阅地址只在 msub 运行时才能访问。黑色窗口就是程序本身，
  关闭这个窗口 = 退出程序。想一直可用，让它保持运行（可以最小化）。
* 默认只有本机能访问，不会弹出 Windows 防火墙提示。
* 想让手机使用（手机和电脑连同一个 Wi-Fi）：
  管理页面 → 设置 → 打开「局域网访问」→ 重启本程序，
  Windows 防火墙弹窗时选「允许」。
  局域网内网页管理使用 HTTP，请只在可信的家庭网络里开启。
* 手机要在外面（不在同一 Wi-Fi）也能用，请把订阅放在一直在线的 VPS 上，
  用 Linux 版 msub，而不是这个电脑版。

【数据在哪里】
* 全部数据（节点、设置、订阅文件）都在程序旁边的 data 文件夹里。
* 备份或换电脑：复制整个 data 文件夹即可。
* 如果程序所在位置不能写入（例如放在 C:\Program Files），
  数据会改存到 %APPDATA%\msub。

【升级 / 卸载】
* 升级：下载新版压缩包，解压后覆盖程序文件，保留原来的 data 文件夹。
* 卸载：关闭程序，删除整个文件夹。不会在系统里留下任何东西。

【黑色窗口里的命令】
  o   重新打开管理页面
  l   显示订阅链接
  r   立即刷新
  q   退出

【杀毒软件 / SmartScreen 提示】
本程序没有购买代码签名证书，Windows 可能提示「未知发布者」，
个别杀毒软件可能误报。出现 SmartScreen 蓝色提示时：
点「更多信息」→「仍要运行」。源代码是公开的，也可以自己打包。
