msub 订阅合并工具（Windows 绿色版）
==========================================

【怎么用】
1. 把压缩包完整解压到任意文件夹（不要在压缩包里直接运行）。
2. 双击 msub.exe。没有黑色窗口：程序会在屏幕右下角的系统托盘出现一个
   蓝色图标（可能收在「^」折叠里），同时弹出 msub 的独立窗口。
3. 第一次使用，窗口里会让你设置登录密码（至少 8 位）。设置后自动进入。
4. 在窗口的「添加节点」里粘贴其他 VPS 的订阅地址或节点链接，
   点「检查」，再点「生成合并链接」。
5. 在「订阅链接」页复制地址，粘贴到电脑上的 v2rayN、Clash 等客户端里。

【托盘图标】
* 双击托盘图标，或右键 → 打开窗口：重新打开窗口。
* 右键菜单：在浏览器中打开 / 复制订阅链接 / 立即刷新 /
  打开数据文件夹 / 开机自启 / 退出。
* 重要：关闭窗口不会退出程序，程序仍在托盘里运行，订阅链接仍可访问。
  要真正退出，请右键托盘图标 → 退出。
* 勾选「开机自启」后，开机时程序只在托盘里静静运行，不会弹出窗口。

【一定要知道】
* 订阅地址只在 msub 运行时才能访问（托盘里有图标就是在运行）。
* 默认只有本机能访问，不会弹出 Windows 防火墙提示。
* 想让手机使用（手机和电脑连同一个 Wi-Fi）：
  窗口里 设置 → 打开「局域网访问」→ 托盘右键「退出」后重新打开，
  Windows 防火墙弹窗时选「允许」。
  局域网内网页管理使用 HTTP，请只在可信的家庭网络里开启。
* 手机要在外面（不在同一 Wi-Fi）也能用，请把订阅放在一直在线的 VPS 上，
  用 Linux 版 msub，而不是这个电脑版。

【窗口打不开 / 出问题时】
* 窗口是用你电脑上的 Edge（没有则用 Chrome）的「应用模式」打开的，
  不需要额外安装任何东西。两者都没有时会改用默认浏览器。
* data\msub.log 是运行日志，反馈问题时请附上它。
* msub-console.exe 是带黑色窗口的版本，能直接看到程序输出，
  排查问题时可以用它代替 msub.exe（两者共用同一份数据）。
* 托盘图标没出现：看任务栏右下角「^」折叠区；如果仍没有，程序会在后台运行，
  用 msub-console.exe 或浏览器访问窗口里显示的地址也能管理。

【数据在哪里】
* 全部数据（节点、设置、订阅文件、日志）都在程序旁边的 data 文件夹里。
* 备份或换电脑：复制整个 data 文件夹即可。
* 如果程序所在位置不能写入（例如放在 C:\Program Files），
  数据会改存到 %APPDATA%\msub。

【升级 / 卸载】
* 升级：托盘退出程序，下载新版压缩包，解压后覆盖程序文件，保留原来的 data 文件夹。
* 卸载：托盘退出程序，先在托盘菜单里取消「开机自启」，再删除整个文件夹。

【杀毒软件 / SmartScreen 提示】
本程序没有购买代码签名证书，Windows 可能提示「未知发布者」，
个别杀毒软件可能误报。出现 SmartScreen 蓝色提示时：
点「更多信息」→「仍要运行」。源代码是公开的，也可以自己打包。
